
# Python - Serialization

This Holberton School project explores serialization and deserialization in Python.

## Learning Objectives

- Understand serialization and deserialization.
- Save and load Python dictionaries using JSON.
- Serialize custom Python objects using pickle.
- Convert CSV files into JSON.
- Serialize and deserialize data using XML.
- Practice file handling and exception management.

## Tasks

0. Basic Serialization — JSON
1. Pickling Custom Classes
2. Converting CSV Data to JSON
3. Serializing and Deserializing with XML

## Technologies

- Python 3
- JSON
- Pickle
- CSV
- XML ElementTree
